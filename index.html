业务流程

21 条流程 ｜ 每一步均可点击跳转到对应页面，演示时按流程逐页讲解
1 供应商准入流程FLOW-ACCESS供应商

自助注册 → 资质初审 → 实地考察与样品评估 → 准入评审 → 建档与品类授权，全过程留痕，支持打印《供应商准入评审表》。

1供应商自助注册供应商 2资质初审采购主管 3实地考察 / 样品评分采购员 4准入评审分管领导 5建档与品类授权采购主管 6一企一档台账采购员
2 品类与商品定价流程FLOW-PRICE供应商

按物资 / 供应商 / 校区维护执行价目，单级审批由分管领导签批，支持变价、延期、蔬果周调价与限期开放。

1新增定价 / 批量导入采购员 2蔬果每周调价发布采购员 3供应商填报报价供应商 4比价与核定采购主管 5价格审批（单级）分管领导 6执行价目与到期预警采购员
3 新品新增申报与办公会会签流程FLOW-NEWITEM供应商

食堂管理人员填报并签名 → 采购车间主任审核签名 → 分管副主任审核签名 → 综合办发起办公会会签。同一人员前序已签的，会签环节不再重复生成待签任务。

1填报并电子签名食堂管理人员 2采购车间主任审核采购车间主任 3分管副主任审核分管副主任 4综合办发起会签综合办 5办公会在线会签（去重签名）办公会成员 6写入物资字典待定价采购车间
4 食堂 / 档口采购计划流程FLOW-PLAN采购

常规明日、紧急当日、提前预约三种计划类型；按物资类别自动分流；须上传当日菜谱；支持草稿、复制历史计划与撤回。

1编制计划并上传菜谱档口负责人 2拍照识别 / Excel 导入食堂管理人员 3提交与撤回档口负责人 4采购组数量核定采购员 5单级审核采购主管 6临时补单档口负责人
5 采购计划审核与派单流程FLOW-ORDER采购

按供应商与品类自动拆单生成采购订单，经确认后派单下发，站内消息与短信双重推送供应商接单。

1拆单生成订单采购员 2派单下发采购主管 3供应商接单供应商 4订单查询与详情采购员
6 缺货反馈与改派流程FLOW-SHORTAGE采购

供应商缺货反馈 → 系统按品类授权、价格有效、及时率与考评等级推荐改派对象 → 采购主管确认 → 原单部分或整单作废、新旧单关联；超时未处理自动升级。

1供应商提交缺货反馈供应商 2缺货处理采购员 3改派推荐与下单采购员 4采购主管确认采购主管 5超时升级提醒分管领导
7 备货打码与发货配送流程FLOW-DELIVERY配送

未上传农残 / 检测报告的不能生成送货二维码；备货须打印粘贴溯源码；发货登记运输信息；冷链须登记在途温度。

1上传每日检测报告供应商 2备货与溯源打码供应商 3发货登记供应商 4在途温度登记供应商 / 司机 5在途跟踪与延误预警采购员
8 到货验收与评分流程FLOW-ACCEPT验收

物资直送下单食堂，由验收员、保管员会同监督员当场验收。扫码调单 → 云秤称重自动去皮 → 规格品牌价格一致性核验 → 合格 / 部分合格 / 不合格判定 → 多维评分 → 三方签字。

1扫码调单验收员 2称重与自动去皮保管员 3一致性核验与拍照验收员 4部分合格分量处理验收员 5多维评分验收员 6三方电子签字保管员 / 验收员 / 监督员
9 入库上架流程FLOW-INBOUND仓储

入库单由验收合格自动生成，处于待上架状态时库存不变；扫库位逐项上架，全部完成后库存才增加并核销在途量。

1自动生成入库单系统 2扫码上架与批次登记保管员 3库存增加与在途核销系统 4打印入库单归档保管员
10 出库领用与签收流程FLOW-OUTBOUND仓储

领用申请 → 审核（校验库存与档口定额）→ 按先进先出推荐批次配货 → 出库单确认时扣减库存 → 领用方电子签收；拒收或部分签收按原批次回冲并登记差异。

1提交领用申请档口负责人 2领用审核保管员 / 食堂主任 3按批次配货出库保管员 4电子签收领用方 5拒收与差异登记保管员 6差异审批分管领导
11 食堂间调拨流程FLOW-TRANSFER仓储

调出方发起 → 调出方负责人审批 → 调出出库扣减库存 → 调入方接收验收并登记差异 → 双向记账并联动成本。

1发起调拨申请调出方食堂 2调出审批食堂主任 3调出出库保管员 4调入接收与差异调入方食堂 5双向记账系统
12 主食车间加工与配送流程FLOW-STAPLE仓储

米面原料直送主食车间验收入库 → 加工领料并登记出成率 → 汇总各食堂需求分单 → 成品配送出库 → 食堂接收，按调拨规则双向记账。

1原料验收入库车间保管员 2加工领料车间负责人 3出成率登记车间负责人 4需求汇总与分单车间负责人 5成品配送出库车间保管员 6食堂接收食堂保管员
13 采购退货流程FLOW-RETURN验收

验收不合格、重量差异较大或抽检不合格的发起退货，经食堂主任审批、供应商现场签字后生效，自动冲减验收单与入库单并重新打印。

业务口径说明

全系统统一口径，避免歧义与账实不符
库存更新时点

验收合格生成入库单时库存不变；入库单全部明细完成上架确认后库存增加；出库单确认出库时扣减；调拨在调出方确认出库时扣减、调入方确认接收时增加；盘点差异在审批通过后调整；退货、拒收与退库在单据生效时按原批次回冲。直进直出类物资不产生库存，验收后直接结转领用成本。

批次先进先出排序键

按「到期日 → 入库日 → 批次号 → 库位」四级依次比较，保证任一时点推荐批次唯一且可复现。临期批次优先于先进先出；原则上不允许人工变更推荐批次，特殊情况须食堂主任授权并填写理由。

部分合格处理

须分别录入合格数量与不合格数量，系统按合格数量生成入库单、按不合格数量生成退货单，两者之和必须等于实收数量，不平的单据自动拦截。合格与不合格部分均须分别拍照留证。

配送与仓储模式

取消中心仓与二次配送，全部物资由供应商按采购订单直送下单食堂。主食车间是唯一保留集中加工配送职能的单位，保留独立库存，其成品配送按与食堂间调拨一致的规则双向记账。

水电气核算

日常按全年水电气费用占营业额 3%~5% 的平均比例自动计提每日经营成本并备注预估依据；每月取得实际抄表数据后人工录入修正；占比超出常规范围的实时预警。

单据状态机

草稿 → 待审核 → 审核中 → 已驳回 / 已通过 → 执行中 → 已完成 / 已作废。草稿仅本人可见且不占正式单号；已提交未审核的可撤回修改；审核完成并进入结算周期后单据不可更改，只能红字冲销后重新补录。

数据权限与脱敏

按「角色权限 + 数据权限」双重控制，菜单、按钮、数据行三级独立授权。各食堂与档口人员仅可查看和操作本组织范围内的数据；采购中心与中心领导可跨组织汇总；供应商仅可查看与本企业相关的订单、对账与考评数据。人事与工资按「本人可见本人、食堂负责人可见本食堂、人事专员与中心领导可见全部」分级，身份证号、银行账号、薪酬字段按权限脱敏。

工资核算公式

食堂工资可分配额 =（本月营业额 − 本月支出）× 上缴比例 + 上月余额，其中本月支出含水电燃气与食材成本（取自出库成本），营业额取自校园一卡通。一线员工绩效工资 = 岗位系数 × 食堂当月绩效分值 × 实际出勤天数；工龄工资 = 有效工龄 × 30 元，上限 240 元。

用工风险限值

劳务派遣人员男性须小于 59 周岁、女性小于 54 周岁；劳务协议人员男性小于 65 周岁、女性小于 60 周岁。超出限值自动标记风险。按首次来校时间自动计算累计工作年限（扣除间断时段），接近八年累计用工期限的提前预警。

维修时效

按紧急程度设置受理与到场响应时限：2 小时内受理接单、4 小时内现场处置，超时未受理或未完成的逐级提醒至站长与分管领导。
